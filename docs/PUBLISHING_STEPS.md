# New GitHub repository — publishing checklist

1. Create a **new** public GitHub repository, for example `india-banking-rbi-powerbi` (distinct from the previously uploaded `india-banking-portfolio`). Leave automatic README disabled, since one is included.
2. Extract the clean ZIP. Upload the **contents** of `india-banking-portfolio-clean/` to the repository root using GitHub's `Add file → Upload files` (do not upload the ZIP itself).
3. Check that `README.md` is at the root, alongside `assets/`, `dashboard/`, and `docs/`.
4. Verify that all three screenshots render within the README and correspond to 2025.
5. Download `dashboard/India_Banking_Portfolio_Final.pbix` from GitHub and open it in Power BI Desktop to confirm it is the correct report.
6. Only after the replacement is good, archive or mark the previous repository as superseded; do not delete the old repository until you are satisfied.

**Do not upload:** previous inaccurate ZIP, stale screenshots, made-up raw data, the externally modified PBIX that would not open, or any fourth-page reference.
